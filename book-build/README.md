# HTR Book — Formatting & Build Pipeline Documentation

This folder contains everything that turns the Markdown manuscript
(`HTR_Book_v42.md`, in the repo root) into the styled Word document
(`HTR_Book_v42.docx`). Keep this folder. It is how all formatting/styling is
applied, and it is reusable for every future edition and every new piece of
content.

**Golden rule:** the manuscript lives in Markdown (`../HTR_Book_v42.md`). The
`.docx` is *generated* — never hand-edit the `.docx`, because the next build
overwrites it. Edit the Markdown, then rebuild.

---

## 1. How to build the styled book

**Use `./book.sh` — not these commands directly.** It wraps the pipeline, refuses
to build over Google Docs edits that are not yet in the manuscript, and commits
the result. See [BOOK_WORKFLOW.md](../BOOK_WORKFLOW.md).

```bash
cd /Users/baba/Vermont-Health-Platform
./book.sh build
```

The raw pipeline, for reference — running this bypasses the safety check that
prevents overwriting the author's unsynced edits:

```bash
python3 book-build/make_reference.py        # (re)builds the Word style template
python3 book-build/build_docx.py HTR_Book_v42.md HTR_Book_v42.docx --cover book-build/cover.png
```

- Requires: `pandoc` (3.x) and Python `python-docx`. (`Pillow` only needed if you
  regenerate the sequence graphic.)
- Output: `HTR_Book_v42.docx` (repo root).
- For a print PDF: open that `.docx` in Word/Google Docs → **Download as PDF**
  (preserves all styling). No local PDF engine matches the docx styling.

## 2. File-by-file reference

### Build pipeline (the core — keep all of these)

| File | What it does | Re-run when |
| :--- | :--- | :--- |
| **`make_reference.py`** | Builds `reference.docx`, the Word **stylesheet**: body font (Georgia 11), navy Calibri headings, all custom paragraph styles (callouts, StatStrip, PullQuote, Banner, Epigraph, Caption), the HTR table style, page setup. **Edit this to change fonts/colors/sizes globally.** | You change any global style. |
| **`build_docx.py`** | The engine. Runs Pandoc (Markdown→docx with the reference styles) then a Python post-pass that renders all the visual treatments: stat-strip cards, callout boxes, pull-quotes, banner, Key-Concepts styling, captions, page breaks, the real TOC, list keep-together, table widths, cover image. **This is where every visual rule lives.** | Every build; edit to add/adjust a treatment. |
| **`reference.docx`** | Generated by `make_reference.py` — the Pandoc style template. Don't hand-edit; regenerate it. | Auto (don't touch). |

### Content-transform scripts (one-time cleanups — kept for reference / reuse on new content)

These were used to clean the v40→v41 manuscript. They are **idempotent** (safe to
re-run) and useful if you paste in new raw/exported content that has the same
artifacts.

| File | What it does |
| :--- | :--- |
| **`transform.py`** | Removes export-artifact escaped chars (`\.` `\+` `\~` `\)` `\(`) and converts inline `**BEYOND VERMONT —** *...*` lines into `CalloutBeyond` fenced divs. |
| **`restore_lists.py`** | Detects bullet lists that an export flattened into plain paragraphs and restores `- ` markers. Conservative; run on a copy first. |
| **`fix_statcards.py`** | Converts broken single-row "stat-card" pipe tables (with duplicated labels) into clean `CalloutKey`/StatStrip strips. |
| **`wrap_vip.py`** | Wraps each `Vermont in Practice:` block in a `CalloutVT` green fenced div. |
| **`add_handson.py`** | Inserts the "Work This Chapter on the Platform" sections into pillar chapters. |
| **`make_sequence_graphic.py`** | Generates `sequence_graphic.png` (the crisp 6-stage timeline figure) with Pillow. Edit the `STAGES` list to change content/colors. |

### Assets

| File | What it is |

## 3. The callout / visual style catalog

All visual treatments are invoked from the Markdown with **Pandoc fenced divs**
(`::: {custom-style="NAME"}`). The post-pass in `build_docx.py` renders each. This
is the consistent vocabulary — use these and nothing else, so styling stays
uniform.

| Style name | Look | Use for |
| :--- | :--- | :--- |
| `StatStrip` | Horizontal navy cards: big number + small label | 3–4 headline numbers |
| `CalloutBeyond` | Teal box, "BEYOND VERMONT" | Generalizing Vermont's lesson to other states |
| `CalloutWorked` | Amber box, "WORKED EXAMPLE" | Worked numeric/scenario walkthroughs |
| `CalloutTry` | Indigo box, "TRY THIS" | Hands-on platform exercises |
| `CalloutKey` | Slate box, "KEY ..." | Key numbers / key takeaways / framed lists |
| `CalloutVT` | Green box, "VERMONT IN PRACTICE" / "VERMONT EVIDENCE" / "GO DEEPER" | Vermont applied examples, evidence, Academy pointers |
| `Banner` | Full-width light-navy bar, centered | A single punchy thesis statement |
| `PullQuote` + `QuoteAttr` | Italic quote + small attribution | Attributed quotations |
| `Epigraph` | Indented italic | Section/chapter opener epigraph |

Plus automatic treatments (no markup needed — the post-pass detects them):
- **Key Concepts** sections → term in **bold blue (#2E74B5) 10pt**, definition 9pt.
- **Sources** blocks → small 9pt italic gray.
- **Figure/Table captions** (`*Figure X — ...*`) → small italic, hugging the table above.
- **Tables** → full text width, navy header, content-driven column widths.

See `TEMPLATES.md` (in this folder) for copy-paste Markdown for each.

## 4. Fonts / sizes (current)

- **Body:** Georgia 11pt, 1.3 line spacing
- **Headings:** Calibri, navy `#1B3A6B` (H1 17 / H2 13.5 / H3 11.5pt)
- To change globally: edit `make_reference.py` (the `font()`/`space()` calls) and rebuild.

## 5. Known follow-ups

- **Narration audio** is keyed to chapter numbers in `frontend/lib/narration.ts`;
  if chapters are renumbered, the audio must be regenerated (TTS) to match.
- A true **print PDF** is best produced from the `.docx` via Word/Google Docs export.
